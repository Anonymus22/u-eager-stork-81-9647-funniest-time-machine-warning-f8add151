# Funniest Time Machine Warning Label

A single safety notice for a time machine, written with a straight face: it warns travellers never to meet their past self, then quietly turns the traveller into both the witness and the suspect of their own incident report. The hazard is a real one — running into yourself — and the punchline lands on the very last words.
